Raman Peak Fitting

1) xlsx 업로드 → Run → 자동 검출/피팅
■ 편집
  · anchor 빨간 ● 점 좌클릭 드래그 → baseline 조정 · peak ▼ 드래그 → center 이동
  · 우클릭: 위 패널→anchor 제거 / 아래 패널→peak 제거
  · Add Anchor Mode ON 후 위 패널 클릭→anchor 추가 · Add Peak Mode ON 후 아래 클릭→peak 추가
■ 그래프 보기 (Plotly 기본)
  · 드래그(빈 영역) → 박스 줌 · 더블클릭 → 줌 리셋(전체 보기)
  · 마우스 휠 / 축 위 드래그 → 확대·축소 · 우상단 툴바로 pan/zoom/저장 전환
  · ※ 편집(드래그·우클릭)과 줌이 헷갈리면, 줌은 그래프 빈 영역에서만 하세요
